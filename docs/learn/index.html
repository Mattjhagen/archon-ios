How it works

Interactive code editors

Every lesson includes a live code editor with a real-time output preview. Edit the code on the left, see the result on the right instantly. No setup required.

Quizzes & rewards

Test your understanding with multiple-choice quizzes. Earn XP for correct answers, build streaks for bonus points, and unlock achievement badges as you progress.

Progress tracking

Your completed lessons, XP, and achievements are saved locally. Pick up exactly where you left off and watch your skills grow.
