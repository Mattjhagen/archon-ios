Support

Get help with Archon. Report bugs, ask questions, and find answers.

GitHub Issues

The fastest way to get help or report a bug is through GitHub Issues. You can also request features and track the status of known issues.

🐛
Report a Bug
Found something broken? Open a bug report with steps to reproduce and your device/iOS version.
💡
Request a Feature
Have an idea for Archon? Share it on GitHub and the community can discuss and vote.

Email

For questions that aren't covered by the documentation or GitHub Issues, you can reach us by email. We read every message and will get back to you as soon as we can.

Email: support@archon.app

Response Times

We aim to respond to all inquiries promptly:

  • GitHub Issues: We monitor issues regularly and aim to respond within 48 hours. Critical bugs are prioritized.
  • Email: We typically respond within 1–3 business days.
  • Security issues: Report security vulnerabilities privately via email. These are handled with highest priority.

What Support Covers

We can help with:

  • App installation and account setup
  • Using the AI Builder, Code Browser, Live Preview, and other features
  • Troubleshooting build failures and app crashes
  • API key configuration and provider setup
  • Understanding your privacy and data
  • Accessibility and usability questions

For developer-related questions about the Archon codebase, architecture, or contributing, see the Developer documentation.
