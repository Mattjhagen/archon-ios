What Archon does

✨
AI Builder
Describe an app in chat. The AI builds it with a visible task timeline, streaming response, and automatic model fallback.
</>
Code Browser
Navigate the generated file tree and read syntax-highlighted source in Swift, JavaScript, TypeScript, HTML, CSS, or JSON.
▶
Live Preview
See your app running in a WKWebView. Go full screen to test the experience before you share it.
📁
Projects
Create, search, and organize projects from your dashboard. Pick up where you left off with full history.

Quick start

Install Archon
Download Archon from the App Store. Requires iOS 17 or later. Install guide →
Create your account
Sign in with your email or use Apple Sign In. Your sessions are stored securely in the iOS Keychain. Create account →
Build your first app
Open the Builder tab, describe what you want, and watch Archon build it in real time. Start building →
